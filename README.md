# THE_TNE_code

This repository contains the simulation and plotting scripts used for the study of anomalous Hall and Nernst effects driven by static and fluctuating spin chiralities on the kagome lattice.

## Repository contents

- `MC_parrall.py`  
  Monte Carlo simulation code for generating kagome-lattice phase data.

- `plot_fig2.py`  
  Plotting script for Fig. 2.

- `plot_fig3_abc.py`  
  Plotting script for Fig. 3(a-c).

- `plot_fig3d_2.py`  
  Plotting script for Fig. 3(d).

- `plot_fig4.py`  
  Plotting script for Fig. 4.

- `plot_fig5.py`  
  Plotting script for Fig. 5.
